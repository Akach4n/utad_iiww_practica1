# Práctica 1 · Diseñando una red social

Diseño y primer prototipo de **Vidora**, una red social de vídeos, hecho con **Astro**.

## Puesta en marcha

Requiere Node 22.23.4 o superior.

```bash
pnpm install
pnpm dev               # desarrollo en http://localhost:4321
```

## Entregables

En la carpeta `docs`:

- Wireframes de cada pantalla
- Diagrama de flujo de interacción
- Mapa de navegación
- Documento con las decisiones de diseño
